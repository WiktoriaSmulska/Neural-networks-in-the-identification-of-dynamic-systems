## Eksperymenty LSTM

### 1. Wpływ rozmiaru warstwy ukrytej

Dla konfiguracji bazowej `seq_len=200`, `stride=100`, `num_layers=2`, `dropout=0.0` sprawdzono wpływ parametru `hidden_size`.

#### hidden_size = 16

Confusion matrix na zbiorze TEST:

```text
[[   0    0    2    0   36]
 [   0 1800    0    0    0]
 [   0    0 1800    0    0]
 [   0    0    0 1592    0]
 [   0    0    0    0 1800]]
```

Accuracy test: 99.46%
Czas uczenia: 32.62 s

Wariant z `hidden_size=16` osiągnął wysoką dokładność ogólną, ale nie rozpoznał klasy Ueda. Próbki tej klasy zostały błędnie przypisane głównie do klasy Rucklidge.

#### hidden_size = 32

Confusion matrix na zbiorze TEST:

```text
[[  38    0    0    0    0]
 [   0 1800    0    0    0]
 [   0    0 1800    0    0]
 [   0    0    0 1592    0]
 [   0    0    0    0 1800]]
```

Accuracy test: 100.00%
Czas uczenia: 65.29 s

Dla `hidden_size=32` model poprawnie sklasyfikował wszystkie próbki testowe. Był to najlepszy wariant pod względem kompromisu między skutecznością a czasem uczenia.
